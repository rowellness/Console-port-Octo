# Steam Input — v0.2 contract

ConsolePortOcto does not configure Steam Input itself.

Recommended logical outputs:

- X -> 1
- Y -> 2
- B -> 3
- D-pad Up -> 4
- D-pad Right -> 5
- D-pad Down -> 6
- D-pad Left -> 7
- A -> player's normal Jump key on BASE ONLY
- LT -> Shift
- RT -> Ctrl
- LT+RT chord/action layer -> Alt

Movement:
- left stick -> WASD
- right stick -> mouse movement used for camera rotation
- do not map right-stick vertical to zoom

Target/interact and UI-mode outputs will be finalized after the v0.2 HUD is tested on the actual OctoWoW client.
