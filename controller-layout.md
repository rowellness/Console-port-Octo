# Controller Contract

## Gameplay

- LT = Shift
- RT = Ctrl
- LT+RT = Alt
- A = Jump on base only
- B = 3
- X = 1
- Y = 2
- D-pad = 4–7
- Left bumper = closest target
- Right bumper = cycle next closest target
- Right trackpad click = interact/loot
- Left stick = WASD
- Right stick = camera rotation only; no zoom

## Left trackpad

- Up = Character
- Down = Spellbook
- Left = All Bags
- Right = Talents

## UI state target behavior

When supported panels are open:
- D-pad = navigation
- A = select / confirm / pickup
- Y = use / equip
- B = cancel

Version 0.2 detects and displays the UI state but intentionally does not steal/rebind the 4–7 keys yet.

## Mouse mode target behavior

- Left-stick click toggles mouse mode
- Right trackpad = cursor
- Right trackpad click = right-click

Version 0.2 has the addon-side mouse-mode state and HUD indicator. The physical toggle/input bridge is a later milestone.
